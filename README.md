# SWOP-rooster

Blok voor Google Sites (Invoegen > Insluiten > Code insluiten) dat een student zijn groepen en lessen toont en als agendabestand (.ics) laat downloaden.

- Bevat zelf geen roosterlinks of namen van studenten.
- Haalt het resultaat op via het Ufora-bestand (`ufora-rooster.html`, achter de Ufora-login), via een verborgen kader of een klein pop-upvenster, met `postMessage`.
- Optionele meldknop stuurt een melding naar een Google Form.

`index.html` is hetzelfde bestand als het Google Sites-blok.
